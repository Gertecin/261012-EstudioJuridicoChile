# 261012 — Estudio Jurídico de Familia, Viña del Mar

Sitio institucional sobrio, accesible y responsivo para un estudio de abogadas
de familia en Viña del Mar, Chile. Desarrollado con **React + Vite + Tailwind CSS**.

![HTML5](https://img.shields.io/badge/React-18-61DAFB?style=flat&logo=react&logoColor=black)
![Tailwind](https://img.shields.io/badge/Tailwind-3.4-38B2AC?style=flat&logo=tailwindcss&logoColor=white)
![Vite](https://img.shields.io/badge/Vite-5-646CFF?style=flat&logo=vite&logoColor=white)
![Responsive](https://img.shields.io/badge/Responsive-Sí-4CAF50)

## Características

- ✅ 6 páginas (Home, Sobre nosotras, Áreas, FAQ, Contacto, Términos legales).
- ✅ React 18 + React Router para navegación SPA.
- ✅ Tailwind CSS con paleta personalizada (azul petróleo, dorado, blanco roto).
- ✅ Tipografías Playfair Display + Plus Jakarta Sans (Google Fonts).
- ✅ Menú responsivo con indicador de sección activa.
- ✅ Formulario de contacto con validación y guardado en `localStorage`.
- ✅ Banner de cookies con preferencia persistente.
- ✅ Acordeón FAQ accesible (teclado + mouse).
- ✅ Mobile-first, sin desbordes horizontales.
- ✅ Sin texto lorem ipsum.

## Cómo arrancar en local

### Requisitos
- **Node.js 18+** (descargar en https://nodejs.org)
- **npm** (viene con Node.js)

### Pasos

```bash
# 1. Clonar el repositorio
git clone https://github.com/Gertecin/261012-EstudioJuridicoChile.git
cd 261012-EstudioJuridicoChile

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run dev
